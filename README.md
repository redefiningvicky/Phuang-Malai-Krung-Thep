<h2 id="objective">🎯 Objective</h2>

<p>
  This project presents a collection of visually engaging
  pamphlets compiled on a website to explore Thailand's
  cultural relationship with water and its climate resilience
  challenges through design, photography, writing, and mapping.
</p>
